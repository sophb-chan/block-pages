# How to Contribute

If you want a block page to be hosted here, there are 2 ways you can make it happen:
1. By creating a pull request
2. By opening an issue

## Method 1

Your pull request should be labeled clearly, like "\[ADDED BLOCK PAGE] Lightspeed".

It should follow the structure of other block pages (following the previous example, `/lightspeed`),
and you should NOT edit the `index.html` to list the block page.
That'll be done after the pull request has been merged with `main`.

## Method 2

Your issue should have a clear title, like "Block page request: Deledao".
We will NOT accept screenshots as examples,
it's STRICTLY REQUIRED to link either a website or add an HTML code with a self-contained copy of the block page.

Page request issues that DON'T follow this pattern will be IGNORED.
